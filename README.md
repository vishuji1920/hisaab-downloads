# Hisaab desktop downloads

This repository hosts public Hisaab desktop installers. Download the latest
Windows, macOS, or Linux package from the [latest release](../../releases/latest).

The application source remains in the private
[build-something-nice-34 repository](https://github.com/vishuji1920/build-something-nice-34).

macOS installers may be unsigned. Windows installers are currently unsigned as
well, so the operating system may show a security warning before installation.
